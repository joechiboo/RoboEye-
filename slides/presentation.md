## Slide 3 — CNN 怎麼「看」圖片（45s）

### 畫面內容

- CNN 架構圖：Input → Conv → Pooling → Conv → Pooling → FC → Output
- 旁邊放「人臉經過 Conv 後的 feature map」視覺化圖
- 關鍵字：局部特徵、權重共享、平移不變性

### 講稿

> 看完 demo，接下來講背後的原理。
>
> CNN 的核心是用一個小的 filter 像滑動窗口掃過整張圖片，每次掃過就提取出局部特徵——邊緣、紋理、輪廓。
>
> 經過多層 Convolution 和 Pooling，網路就能從低階邊緣慢慢組合出高階語意，像眼睛、皺紋、臉型，最後透過全連接層整合做判斷。

## Slide 4 — 三種年齡預測方法（1min）

### 畫面內容

- 三欄對比表：

  | 方法 | 論文 | 核心思路 |
  |---|---|---|
  | DEX | Rothe et al., ICCV 2015 | 101 類 softmax → 期望值 |
  | REGA | Real-Time Emotion, Gender, Age Review | 即時多任務統一管線 |
  | Transfer Learning | arXiv 2021 | 輕量模型 + 遷移學習 |

- DEX 流程圖：人臉 → CNN → 101 個 softmax → 期望值 = 預測年齡
- 小字：IMDB-WIKI 50 萬張，ChaLearn 2015 冠軍

### 講稿

> 我們研究了三篇代表性論文。
>
> 第一篇 **DEX**——直覺會想直接回歸預測年齡，但 DEX 把 0-100 歲切成 101 類，先分類再算期望值。這方法在 2015 年國際競賽拿下冠軍，比人類還準。
>
> 第二篇 **REGA**——把年齡、性別、情緒整合在同一個即時管線裡。
>
> 第三篇**遷移學習**——用 MobileNet 等輕量模型達到接近大模型的效果。

## Slide 6 — 工程實作 1：跨框架整合與預處理（1min）

### 畫面內容

- **跨框架模型整合**：Caffe / PyTorch / InsightFace → 統一轉 ONNX
- **純瀏覽器推論**：ONNX Runtime Web (WASM) — 無後端、無安裝
- **預處理對齊**（最容易出錯的一環）：

  | 模型 | 通道順序 | 歸一化 |
  |---|---|---|
  | Caffe | BGR | mean=(78.4, 87.7, 114.9), no scale |
  | DEX | RGB | ImageNet mean/std |
  | InsightFace | RGB | mean=0, scale=1, swapRB |

- 小字：「任何一個細節對錯，預測就會完全偏掉」

### 講稿

> 接下來講工程細節。
>
> 第一個挑戰是**跨框架整合**——三個方法分別來自 Caffe、PyTorch、InsightFace。我們把它們都轉成 ONNX，這樣就能用同一套 ONNX Runtime Web 在瀏覽器跑，不需要後端、不需要安裝。
>
> 第二個是**預處理對齊**——這是最容易出錯的地方。每個模型訓練時用的歸一化都不同，任何一個細節對錯預測就會偏掉。我們花了不少時間 trace 這些細節，確保瀏覽器端輸出跟原始 Python 一致。

## Slide 7 — 工程實作 2：對齊、穩定化、量化評估（1min）

### 畫面內容

- **人臉對齊**：face-api.js 68-landmark → 5 點仿射變換
  - 眼睛、鼻子、嘴角對齊到標準位置
  - InsightFace 準確度顯著提升
- **預測穩定化**：
  - 年齡：3 秒滑動窗口 + P20-P80 離群值修剪
  - 性別：2 秒多數決 + 信心區間
  - FPS：4 秒平均
- **量化評估工具**：10 樣本 benchmark
- **部署細節**：GitHub Pages 不支援 Git LFS → 改用嵌入權重的單一 ONNX 檔

### 講稿

> 第三個是**人臉對齊**——一開始 InsightFace 不太穩，後來發現原始實作會用臉部關鍵點做仿射變換把臉擺正。我們用 face-api.js 偵測 68 個關鍵點，挑出眼睛、鼻子、嘴角做對齊，準確度明顯提升。
>
> 第四個是**預測穩定化**——即時推論每幀結果都會跳動，所以加上滑動窗口加離群值修剪。
>
> 第五個是**量化評估工具**，就是剛剛 demo 看到的，讓比較不只是「看起來準」而是有客觀數據。
>
> 部署上也踩了個坑——GitHub Pages 不支援 Git LFS，模型權重必須直接嵌入單一 ONNX 檔才能正確載入。
